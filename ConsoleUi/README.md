# ConsoleUi

Общая библиотека интерфейса для консольных лабораторных на .NET 10.
Использует Spectre.Console 0.57.2. Не зависит от алгоритмов лабораторных.

## Демо

Откройте `ConsoleUi.slnx`, назначьте **ConsoleUi.Demo** запускаемым проектом
и нажмите Ctrl+F5. В Windows также можно запустить `RunDemo.cmd`.

```sh
dotnet run --project Demo/ConsoleUi.Demo.csproj
```

В демо доступны все операции. Для выбора файлов есть каталог `Demo/Samples`
с текстовыми файлами, подпапкой и файлом, скрываемым фильтром `.txt`.
Выбор пути сохранения в демо ничего не записывает на диск.

## Подключение к лабораторной

Добавьте ссылку на проект библиотеки (путь относительно проекта лабораторной):

```xml
<ItemGroup>
  <ProjectReference Include="../ConsoleUi/ConsoleUi.csproj" />
</ItemGroup>
```

Пакет Spectre.Console приходит через библиотеку. При первом восстановлении нужен
доступ к NuGet или уже загруженный пакет в кэше. Если в лабораторной есть
`NuGet.Config` с `<clear />`, добавьте источник nuget.org перед восстановлением
на компьютере без этого пакета. При передаче исходников сохраняйте папку ConsoleUi.

```csharp
using ConsoleUi;

var ui = new Ui(); // Один экземпляр на приложение: помнит последнюю папку.
var input = ui.PickFile("Выберите файл для шифрования");
if (input.IsCancelled)
{
    return;
}

var output = ui.PickSavePath("Куда сохранить результат?", "encrypted.bin");
if (output.IsCancelled)
{
    return;
}

// Здесь лабораторная вызывает собственный алгоритм и сохраняет файл.
ui.ShowSuccess($"Выбраны пути: {input.Value} → {output.Value}");
```

## API

| Метод | Параметры | Результат |
| --- | --- | --- |
| `Select<T>` | Заголовок, `IEnumerable<Choice<T>>` | Типизированное значение |
| `PickFile` | Заголовок, начальная папка, необязательный `Func<string, bool>` | Полный путь существующего файла |
| `PickDirectory` | Заголовок, начальная папка | Полный путь папки |
| `PickSavePath` | Заголовок, предлагаемое имя, начальная папка | Полный путь нового файла |
| `ReadText` | Заголовок, значение по умолчанию, валидатор | Непустая строка |
| `ReadNumber<T>` | Заголовок, значение по умолчанию, валидатор | Число: например `int`, `double`, `decimal` |
| `Confirm` | Заголовок | `true` — да, `false` — нет |
| `ShowSuccess`, `ShowError` | Сообщение | Вывод с подписью и цветом |

Все методы ввода возвращают `PromptResult<T>`. Проверяйте `IsCancelled`
перед обращением к `Value`. Отмена отличается от `false`, `0` и ошибки;
`default(PromptResult<T>)` тоже означает отмену.

Валидатор имеет вид `Func<T, string?>`: `null` означает успех,
строка — объяснение ошибки. При ошибке библиотека повторяет ввод.
Программные ошибки в пользовательском валидаторе не скрываются.

```csharp
var count = ui.ReadNumber<int>("Количество (1–100)", 10,
    value => value is >= 1 and <= 100 ? null : "Нужно число от 1 до 100.");

var mode = ui.Select("Режим", new Choice<string>[]
{
    new("Простая замена", "ecb"),
    new("Обратная связь", "cfb")
});

var text = ui.PickFile("Текстовый файл", filter:
    path => Path.GetExtension(path).Equals(".txt", StringComparison.OrdinalIgnoreCase));
```

## Управление и поведение

- Списки: ↑↓, Enter, Esc. Ввод букв ищет по названиям. Есть явный пункт отмены.
- Текст и числа: Enter принимает значение по умолчанию; Esc сразу отменяет ввод,
  даже если часть значения уже набрана. Числа читаются в текущей локали.
- В файловом выборе доступны родительская папка, диски и ручной ввод пути.
  Ручной путь может быть относительным к показанной папке или абсолютным,
  в том числе в кавычках. Фильтр действует и на ручной выбор файла.
- При выборе папки ручной путь открывает её; затем нажмите «Выбрать эту папку».
- Ошибки доступа показываются в интерфейсе. Можно вернуться или выбрать другой путь.
- Сохранение предлагает новое имя и отклоняет занятые имена. Метод не создаёт
  файл и не гарантирует возможность записи позднее: приложение открывает его
  через `FileMode.CreateNew` и обрабатывает ошибки файловой системы.
- При перенаправленном вводе используются номера: `0` — отмена.
  В текстовых полях перенаправленного ввода отмена задаётся строкой `/cancel`.
  При обычном интерактивном вводе `/cancel` — обычный текст, отмена выполняется Esc.
  Конец входного потока отменяет запрос, не зацикливая приложение.
- Названия и сообщения выводятся как текст: квадратные скобки не исполняют разметку.
- Диалоги рассчитаны на последовательные вызовы из одного потока.

## Проверки

```sh
dotnet build ConsoleUi.slnx
dotnet run --project Tests/ConsoleUi.Tests.csproj
```

`ConsoleUi.Tests` — небольшой исполняемый набор проверок без дополнительного
тестового фреймворка: отмена, EOF, проверка ввода, числовое переполнение,
фильтрация файлов, ручные пути, переходы между папками и защита от занятого имени.
Для автоматических сценариев `Ui` принимает `IAnsiConsole` и `TextReader`.

Библиотека собирается из корневого проекта; исходники Demo и Tests исключены
из его компиляции. Эти приложения подключают её через `ProjectReference`.
